# สถานะ "ต้องส่ง 13 แฟ้ม" ในหน้ารายชื่อ รพ.สต.

**วันที่:** 2026-07-03
**หน้าที่เกี่ยวข้อง:** `src/pages/HospList.jsx`

## เป้าหมาย

เพิ่มการแสดงผลในหน้า **รายชื่อ รพ.สต.** ให้เห็นว่า รพ.สต. ใดอยู่ในรายการที่ "ต้องส่ง 13 แฟ้ม"
โดย map จากรหัสสถานพยาบาล (`statement_hcode`) ในไฟล์ Excel ที่ผู้ใช้จัดเตรียมไว้ เข้ากับ
`hospcode` ของแต่ละแถวใน `data.installList`

## ที่มาของข้อมูล

ไฟล์ Excel ต้นทางมี 2 คอลัมน์: `statement_hcode` (รหัส 3-5 หลัก) และ `statement_hname` (ชื่อ)
รวม 81 รายการ จากการตรวจสอบ map เข้ากับ `installData.json` ได้ 72 รายการ
ส่วนที่เหลือ 9 รายการเป็นศูนย์แพทย์ชุมชน / คลินิกหมอครอบครัว ที่ไม่อยู่ในขอบเขตติดตั้ง NHIP

## แนวทาง

### 1. Data file (static bundle)

สร้าง `src/data/statement13.json` เก็บรายการทั้งหมดเป็น array ของ object:

```json
[
  { "hcode": "5406", "hname": "รพ.สต.บ้านห้วยยางดง" },
  { "hcode": "7177", "hname": "รพ.สต.แม่ยื้อ" }
]
```

- ฝังในแอปเป็นค่าคงที่ แก้ไข/เพิ่มรายการภายหลังได้ง่าย (แก้ไฟล์เดียว)
- เก็บ `hname` ไว้เพื่อ traceability แม้ฟีเจอร์จะใช้แค่ `hcode`

### 2. Mapping ใน HospList.jsx

- `import statement13 from '../data/statement13.json'`
- สร้าง `const stmt13Set = new Set(statement13.map(x => String(x.hcode)))` (memoized ครั้งเดียว)
- helper: `const mustSend13 = hospcode => stmt13Set.has(String(hospcode))`

### 3. คอลัมน์ใหม่ในตาราง

เพิ่มคอลัมน์ **"13 แฟ้ม"** (วางถัดจากคอลัมน์ "สรุปรายงาน" หรือท้ายตาราง):

- ตรงกับรายการ → ป้าย **`📁 13 แฟ้ม`** สีน้ำเงิน `#2563eb` (ใช้ helper `badge()` เดิม)
- ไม่ตรง → `–` สีจาง (`var(--text-muted)`)

อัปเดต `colSpan` ของแถว "ไม่พบข้อมูล" จาก 12 → 13

### 4. ตัวกรอง

เพิ่ม `<select>` **"13 แฟ้ม"** สไตล์เดียวกับตัวกรองเดิม:

- `ทั้งหมด` (ค่าว่าง) / `เฉพาะที่ต้องส่ง` / `เฉพาะที่ไม่ต้องส่ง`
- เพิ่ม state `filter13` + รวมเข้าเงื่อนไขใน `filtered` (useMemo dependency)
- รวมเข้าเงื่อนไขปุ่ม "ล้างตัวกรอง" และการ reset

### 5. การ์ดสรุป

เพิ่มการ์ด **"ต้องส่ง 13 แฟ้ม"** ต่อจากการ์ด "ทั้งหมด / กรองแล้ว":

- แสดงจำนวน รพ.สต. ใน `list` ที่ `mustSend13` เป็นจริง (คาดว่า ~72)
- สีน้ำเงิน `#2563eb` ให้เข้าชุดกับป้าย

## ขอบเขต / ข้อจำกัด

- รพ.สต. ในไฟล์ Excel ที่ไม่อยู่ใน `installList` (9 รายการ) จะไม่แสดงในตาราง เพราะตารางนี้
  อ้างอิงจากรายการติดตั้ง NHIP เท่านั้น — เป็นพฤติกรรมที่ถูกต้องตามความจริง
- ไม่มีการไฮไลต์ทั้งแถว (ผู้ใช้เลือกใช้แค่ป้ายในคอลัมน์)
- รูปแบบ hospcode ตรงกันอยู่แล้ว (string เลขล้วน ไม่มีปัญหา leading zero) จึง map ตรงได้ทันที

## Testing / Verification

- เปิดหน้ารายชื่อ รพ.สต. → ตรวจว่ามีคอลัมน์ "13 แฟ้ม" และป้ายขึ้นถูกแถว (เช่น รหัส 5406, 7177)
- ตัวกรอง "เฉพาะที่ต้องส่ง" → นับได้ ~72 รายการ ตรงกับการ์ดสรุป

- ปุ่ม "ล้างตัวกรอง" → รีเซ็ต filter13 ด้วย
